# Booking Platform QA & Project Coordination

## Overview

A university coursework project focused on software quality assurance, test planning, and team coordination for a booking management system.

The goal was to organise and manage testing activities for booking functionality, including successful bookings, invalid requests, scheduling conflicts, cancellations, and notifications.

## My Contributions

- Designed and documented booking-related QA checking requirements.
- Used GitHub Projects and Issues to organise tasks, assign responsibilities, and track progress.
- Identified blocked tasks and adjusted responsibilities based on team workload.
- Broke down broad testing requirements into more manageable checks.
- Documented expected results, evidence requirements, and incomplete work.

## QA Scope

| Test Area | Management Status |
|---|---|
| Test data and timetable display | Done |
| Valid booking creation | Done |
| Missing and invalid information | In Progress |
| Duplicate and overlapping bookings | In Progress |
| Booking updates, cancellations, and unavailable locations | In Progress |
| Email notifications and reminders | In Progress |

*Statuses reflect the coursework management records. "Done" does not necessarily mean all functional testing passed.*
